# ToolKitFree: Free Online Tools, No Sign-Up

[ToolKitFree](https://alltoolkit.net/) is a free set of 80+ online tools for PDFs, images, text, developers and everyday money maths. Everything runs in your browser on a phone or computer. There is no sign-up and no watermark.

**Open the tools:** [alltoolkit.net](https://alltoolkit.net/)

## PDF tools

- [Compress PDF](https://alltoolkit.net/pdf/compress-pdf): make a PDF small enough for form uploads
- [Merge PDF](https://alltoolkit.net/pdf/merge-pdf): join several PDFs into one file
- [Split PDF](https://alltoolkit.net/pdf/split-pdf): cut a PDF into separate files
- [PDF to Word](https://alltoolkit.net/pdf/pdf-to-word) and [Word to PDF](https://alltoolkit.net/pdf/word-to-pdf)
- [JPG to PDF](https://alltoolkit.net/pdf/jpg-to-pdf) and [PDF to JPG](https://alltoolkit.net/pdf/pdf-to-jpg)
- [Edit PDF](https://alltoolkit.net/pdf/edit-pdf) and [Sign PDF](https://alltoolkit.net/pdf/sign-pdf)
- [Protect PDF](https://alltoolkit.net/pdf/protect-pdf) and [Unlock PDF](https://alltoolkit.net/pdf/unlock-pdf)
- [OCR PDF](https://alltoolkit.net/pdf/ocr-pdf): turn a scanned PDF into searchable text

## Image tools

- [Compress Image](https://alltoolkit.net/image/compress-image): bring a photo under 20 KB, 50 KB or any limit
- [Resize Image](https://alltoolkit.net/image/resize-image): set exact pixel sizes for exam and job forms
- [Crop Image](https://alltoolkit.net/image/crop-image)
- [Remove Background](https://alltoolkit.net/image/remove-background)
- [HEIC to JPG](https://alltoolkit.net/image/heic-to-jpg) for iPhone photos
- [Image Converter](https://alltoolkit.net/image/image-converter) for JPG, PNG and WebP
